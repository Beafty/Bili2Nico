B站 vs N站 弹幕模式与指令对比

Bilibili 使用数字 mode；Niconico（N站）使用 mail 命令字符串表达位置、字号、颜色、字体以及 NicoScript 指令。

1. 总览

B 站的弹幕“模式/类型”是一个 数字枚举（来自 DanmakuElem.mode / XML 中的 p 属性第 2 位）。 N 站的弹幕“模式”不是数字，而是写在 mail 字段里的 命令字符串，其中最核心的是位置命令：

维度B站（数字/字段）N站（mail 命令）
模式 / 位置mode：1–9naka / ue / shita
字号fontsize：18 / 25 / 36small / medium / big
字体无defont / gothic / mincho / gulim / simsun
颜色十进制 RGB888（如 16777215）颜色名（red…）或 #RRGGBB（需 premium）
时间progress（毫秒）vpos（厘秒，= 毫秒 / 10）
逆向mode=6（单条弹幕属性）@逆（投稿者 NicoScript，全局时间段）

2. 模式 / 类型对照表

B站 modeB站含义N站等价说明 / 本扩展映射
1 / 2 / 3普通滚动弹幕naka默认右→左
4底部弹幕shita底部居中固定
5顶部弹幕ue顶部居中固定
6逆向弹幕无单条等价（N站为 @逆 全局）本扩展用 naka + reverse:true，左→右
7高级弹幕无直接等价正文是 JSON；本扩展跳过
8代码弹幕无（N站没有代码弹幕）本扩展跳过
9BAS 弹幕无（BAS 是 B站特有，pool 必须为 2）本扩展跳过
注意：B站 mode 2 / 3 在部分实现里历史上有“下端/……滚动”语义，但接口文档归为普通弹幕，本扩展统一按 naka 处理。

3. B站 弹幕字段 / 指令

核心字段

  • mode：弹幕类型 1–9
  • progress：出现时间（毫秒）
  • fontsize：字号 18 / 25 / 36（也出现过 64 等非标准值）
  • color：十进制 RGB888
  • pool：0 普通 / 1 字幕 / 2 特殊（代码/BAS）
  • ctime：发送时间戳
  • content：正文

其他字段

  • midHash：发送者 hash
  • weight：语义屏蔽权重 0–10
  • attr：位标记（保护 / 直播 / 高赞）
  • idStr / id：唯一 ID
  • action / animation：动作 / 动画（高级弹幕用）
  • colorful：大会员专属颜色（`DmColorfulType`，`60001` = 渐变色）

4. N站 弹幕 mail 指令

基础命令

  • 位置：naka / ue / shita
  • 字号：small / medium / big
  • 字体：defont / gothic / mincho / gulim / simsun
  • 任意颜色：#RRGGBB（需 premium）
  • 时长：@数字，如 @3 表示 3 秒
  • 其他：full、ender、_live、184（匿名）等

NicoScript（以 @ 开头，投稿者可用）

  • @逆：全局逆向时间段（可带 全/コメ/投コメ）
  • @デフォルト：设置默认命令
  • @コメント禁止：禁止评论
  • @シーク禁止：禁止跳转
  • @ジャンプ：跳转到指定 sm/so/nm 等
  • @置換：替换文本
  • @ボタン：按钮评论
